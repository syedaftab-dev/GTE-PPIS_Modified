\subsection{Gate Supervision Formulation}

The biophysics-supervised gate loss encodes the hypothesis that
surface-exposed residues (high RSA) should favour ESM-2 sequence context
(gate~$\to 0$), while buried residues (low RSA) should favour classical
3D structure features (gate~$\to 1$):
%
\begin{align}
    g^*_i &= 1 - \text{RSA}_i, \\
    \mathcal{L}_\text{gate} &= \frac{1}{N}\sum_{i=1}^{N}
        \bigl(\hat{g}_i - g^*_i\bigr)^2, \\
    \mathcal{L}_\text{total} &= \mathcal{L}_\text{focal} +
        \lambda_\text{gate} \cdot \mathcal{L}_\text{gate},
        \quad \lambda_\text{gate} = 0.10.
\end{align}
%
RSA values are loaded from \code{Feature/rsa/\{id\}.npy} (FreeSASA, range $[0,1]$).
Fallback 0.5 is used for \texttt{2j3rA} (absent from \code{Feature/rsa/}).

\subsection{Training Convergence}

All five folds converged without collapse.
Training log: Average validation AUC~0.8144, Average validation AUPRC~0.4875.
Best epochs: 19 / 16 / 16 / 17 / 17 (mean 17.0).
Validation thresholds (read from test log): 0.36 / 0.80 / 0.62 / 0.57 / 0.83
(mean 0.636, wide spread --- see Caveats).

\section{Limitations and Caveats}
% ================================================================

\begin{tcolorbox}[colback=warnbg, colframe=warnorange, title=\textbf{Critical Caveats}]
\begin{enumerate}[leftmargin=*]
    \item \textbf{Single run, no seed variance.}
          Both runs use \code{SEED=2024}.  Observed deltas are small enough
          ($|\Delta\text{AUPRC}| \le 0.019$) to fall within typical single-seed
          variance for 5-fold CV at this scale.  No significance testing was
          performed.  Do not treat any delta as confirmed without at least
          $N=3$ seeds per condition.

    \item \textbf{Three simultaneous confounders.}
          The Sep 11 run differs from Aug 13 on three axes at once:
          (a) RSA gate supervision added ($\lambda=0.1$),
          (b) \code{transformer\_residual} True vs.\ False, and
          (c) \code{focal\_gamma} 0.0 vs.\ 2.0.
          It is \emph{not possible} to attribute the observed deltas to RSA
          supervision alone.  A proper ablation requires a run with identical Sep~11
          settings but \code{lambda\_gate=0.0}.

    \item \textbf{UBtest split mismatch with paper.}
          Our UBtest\_31-6 (25 proteins after de-overlap) $\ne$ paper's
          UBtest\_25.  Paper UBtest columns are not directly comparable.

    \item \textbf{Threshold instability.}
          Sep 11 validation thresholds span $\tau^* \in \{0.36, 0.57, 0.62,
          0.80, 0.83\}$ (range 0.47) vs.\ Aug 13's $\{0.46, 0.48, 0.58,
          0.62, 0.64\}$ (range 0.18).  This wide spread may indicate degraded
          probability calibration from the combined loss, rather than better
          interface detection.
\end{enumerate}
\end{tcolorbox}

\section{Next Steps}
% ================================================================

\begin{enumerate}[leftmargin=*]
    \item \textbf{Confounder isolation [Priority 1]:}
          Run \code{python train.py --fusion\_mode gated --d\_proj 128 --focal\_gamma 0.0}
          with \code{lambda\_gate=0.0} (disabled) to obtain a matched baseline
          under identical architecture settings.

    \item \textbf{Multi-seed variance [Priority 2]:}
          Run seeds 2024, 2025, 2026 for both conditions.
          $N=3$ is the minimum for paired testing.

    \item \textbf{$\lambda_\text{gate}$ sweep [Priority 3]:}
          Test $\lambda \in \{0.01, 0.05, 0.1, 0.2\}$.
          Current $\lambda=0.1$ may dominate the classification gradient
          at early epochs.

    \item \textbf{Gate value inspection:}
          Load Sep 11 checkpoints and compute mean $\hat{g}_i$ vs.\ RSA
          correlation.  A properly supervised gate should show a clear
          negative correlation (buried $\to$ gate~$\approx$~1).
          Near-zero correlation would indicate the auxiliary loss is
          being overwhelmed.

    \item \textbf{B-factor gating (scheduled):}
          Once the RSA gate ablation is conclusive, substitute
          $\text{RSA}_i$ with normalised $B_i$ (from PDB ATOM records)
          as the gate target.  The novelty search (Sep 11) confirmed
          this combination has no direct prior in the PPIS literature.
\end{enumerate}

\section*{Summary}

\begin{enumerate}[leftmargin=*]
    \item Git history confirms: gated fusion existed from July 23
          (\texttt{91406bd}), RSA supervision not until September 3
          (\texttt{3b04b2a}).  Aug 13 is definitively an unsupervised-gate run.
    \item Sep 11 is the first end-to-end training with RSA gate supervision.
    \item RSA supervision did not improve AUROC or AUPRC on Test\_60 or
          Test\_315-28.  Only the UBtest AUPRC shows a marginal gain ($+0.007$).
    \item The ESM-2 UBtest advantage is confirmed and preserved under RSA
          supervision; it originates from ESM-2 integration, not from the gate loss.
    \item Three simultaneous confounders prevent attributing the deltas
          to RSA supervision alone.  Confounder isolation is the immediate
          next experiment.
\end{enumerate}
